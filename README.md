## 使用方式

`v1/index.html` 為完整、可離線操作的單檔 HTML；下載後用 Chrome 或 Edge 開啟。支援頁籤、前後頁、全螢幕、電話對話示範及獨立訂單操作；參與表單需要連網。

1. 認識服務：AI 電話點餐、Google 點餐導客。
2. 四大特點：服務額度、現場收款、訂單與硬體導入說明。
3. 體驗接單：看單、接單、手動 Key POS、製作、收款與取餐。
4. 如何加入：門市配合事項、協助流程及參與表單。

通話、訂單與收款互動為展示，不會撥打電話、產生真實訂單或收取餐費。

## 版本規則

V1 保留核定畫面與互動，不覆蓋固定版本。未來變更另建版本目錄與 tag；網站根目錄僅導向現行版本。發布使用 GitHub Pages 的 `main` 分支根目錄。

本 repository 僅保存公開簡報與版本說明；不納入內部文件、歷史草稿、測試截圖或憑證。
